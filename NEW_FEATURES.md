# 🎯 Новый функционал - Выбор получателей и пересылка сообщений

## 📋 Что добавлено:

### 1. ✅ Выбор получателей вручную
- В шаге "Выбор получателей" теперь есть опция "👥 Выбрать вручную"
- Интерфейс с пагинацией по 8 гостей на страницу
- Возможность выбрать конкретных гостей или всех сразу
- Подсчет выбранных получателей
- Кнопка "📨 Отправить выбранным" появляется только если кто-то выбран

### 2. ✅ Автоматическая пересылка сообщений админам
- Все сообщения от обычных пользователей автоматически пересылаются администраторам
- Поддержка текста, фото, видео и документов
- Информация о пользователе: имя, user ID, username
- Пользователь получает подтверждение "✅ Ваше сообщение отправлено администраторам"
- Админы не видят сообщения от других админов

## 🔧 Техническая реализация:

### Файлы:
- `internal/bot/broadcast_recipients.go` - логика выбора получателей
- `internal/bot/admin_forward.go` - пересылка сообщений админам
- Обновлены `internal/bot/callbacks.go` и `internal/bot/bot.go`

### Структуры данных:
```go
type BroadcastRecipientInfo struct {
    UserID      int64
    DisplayName string
    Username    string
    Selected    bool
}
```

### Callback'и для выбора получателей:
- `broadcast:select:{user_id}` - выбрать пользователя
- `broadcast:deselect:{user_id}` - снять выбор
- `broadcast:select_all` - выбрать всех
- `broadcast:deselect_all` - снять всех
- `broadcast:page:{number}` - пагинация
- `broadcast:send_selected` - отправить выбранным

## 📱 Как это работает:

### Для администраторов:
1. Создание рассылки → Шаг 4: Выбор получателей
2. Выбрать "👥 Выбрать вручную"
3. Вид списка гостей с возможностью выбора
4. Пагинация для больших списков
5. Кнопка отправки только при выборе хотя бы одного гостя

### Для обычных пользователей:
1. Любое сообщение (текст/фото/видео/документ)
2. Автоматическая пересылка всем администраторам
3. Получение подтверждения об отправке

### Для администраторов (получение сообщений):
1. Полная информация о пользователе
2. Пересланный контент (фото/видео/документ)
3. User ID для быстрого ответа или блокировки

## 🛡️ Безопасность:
- Проверка прав администратора
- Валидация user ID
- Защита от спама (можно добавить rate limiting)
- Фильтрация админских команд

## 🎉 Преимущества:
- Таргетированные рассылки
- Быстрая обратная связь от пользователей
- Централизованная обработка запросов
- Удобный интерфейс выбора получателей
