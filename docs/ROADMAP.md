# Роадмап проекта

## 1. Что уже сделано

### Продукт

- Собран Telegram-бот с пользовательским и админским сценариями.
- Реализован Telegram Mini App как основная витрина приглашения.
- Работает RSVP/регистрация гостей.
- Есть сценарии проверки регистрации и отмены регистрации.
- Реализованы разделы приглашения: главная, тайминг, меню, дресс-код, рассадка, пожелания, фото.
- Запущены игровые активности: `Dragon`, `Flappy Bird`, `Crossword`, `Wordle`.
- Реализованы рейтинг и звания.
- Добавлены админские рассылки и действия с группой.
- Есть сценарии загрузки фото.

### Интеграции и инфраструктура

- Telegram Bot API интегрирован.
- Telegram WebApp `initData` разбирается и валидируется.
- Google Sheets используется как основное хранилище.
- Есть middleware безопасности, request id, rate limit и structured logging.
- Есть кэширование часто запрашиваемых данных.
- Есть Docker-сборка.
- Есть планировщик ежедневного сброса как отдельный модуль.
- Добавлен базовый GitHub Actions CI.

### Документация и управление проектом

- Зафиксированы актуальные `README`, архитектура, правила и роадмап.
- Уточнён шаблон `.env.example`.

## 2. Что сделано в текущем цикле

- Переставлена нижняя навигация Mini App под целевой пользовательский порядок.
- Начата миграция фото-контура с payload/file id в Google Sheets на единое файловое хранение в Google Drive.
- Приведена документация к реальному состоянию кода.
- Выделен и формализован стек, структура репозитория и контракты Google Sheets.
- Зафиксированы правила разработки и эксплуатации.
- Реализован ежедневный сброс Wordle и Crossword с идемпотентным учётом partial rewards.
- Добавлены unit-тесты на auth/session/initData resolution в backend API.
- Добавлен базовый CI pipeline для backend и frontend.
- Добавлена стартовая self-healing валидация служебных Google Sheets-листов.
- Добавлен операционный чек-лист деплоя и smoke-проверок.
- Подключена опубликованная рассадка по столам в React Mini App через `/api/seating/info` вместо фронтенд-заглушки.

## 3. Главные текущие проблемы

1. Фото-контур не был доведён до полноценного хранения файлов и единой точки сохранения в Google Drive.
2. Ежедневный сброс игр был обозначен, но логика долго оставалась незавершённой.
3. Критичные сценарии identity/auth всё ещё недостаточно покрыты тестами.
4. Google Sheets остаётся сильной точкой связанности и потенциальной хрупкости.
5. Поведение игр частично распределено между frontend, backend и таблицами.
6. Не хватает операционных и продуктовых метрик.
