# Роадмап проекта

## Завершено в текущем цикле

- ✅ Полный production-аудит репозитория и запусков.
- ✅ Cleanup Git: исключены локальные env, бинарники и Vite cache из отслеживаемых артефактов.
- ✅ Backend hardening: request ID переведён на криптографически случайный suffix, debug/auth logging приведён к безопасному production-поведению.
- ✅ Frontend/tooling hardening: удалена неиспользуемая уязвимая runtime-зависимость, исправлен Vite proxy, обновлён dev-tooling стек.
- ✅ Обновлены `README`, `ARCHITECTURE`, `DEPLOYMENT`, `DEPLOY_CHECKLIST`, `CONTRIBUTING`.
- ✅ Добавлены `Makefile` и усиленный CI (backend vet + frontend lint).
